# Elastic Beanstalk

Elastic Beanstalk ist ein Service für die Bereitstellung und Skalierung von
Webanwendungen und Services. Laden Sie Ihren Code einfach hoch und Elastic
Beanstalk übernimmt automatisch die Bereitstellung – von der
Kapazitätsbereitstellung, Lastverteilung und automatischen Skalierung bis zur
Statusüberwachung der Anwendung.
