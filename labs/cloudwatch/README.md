# CloudWatch

Amazon CloudWatch ist ein Service, der Anwendungen überwacht, auf
Leistungsänderungen reagiert, die Ressourcennutzung optimiert und Einblicke in
den Betriebszustand bietet. Durch die Erfassung von Daten aus allen
AWS-Ressourcen bietet CloudWatch einen Überblick über die systemweite Leistung
und ermöglicht es Benutzern, Alarme einzustellen, automatisch auf Änderungen zu
reagieren und sich einen einheitlichen Überblick über den Betriebszustand zu
verschaffen.
